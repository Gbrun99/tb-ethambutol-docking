# Análisis Estructural y Docking Molecular: Ethambutol en EmbC (*M. tuberculosis*)

![Status](https://img.shields.io/badge/Status-Completed-success)
![3D Visualizer](https://img.shields.io/badge/Visualizer-Live-blue)

Estudio computacional de docking molecular para evaluar el impacto de la mutación de resistencia **M306V** en la proteína blanco **EmbC** de *Mycobacterium tuberculosis* frente al fármaco **Ethambutol**.

## Resumen de Resultados (Docking)

* **Wild-Type (Met306):** $\Delta G = -5.147 \text{ kcal/mol}$ (Mayor afinidad de unión)
* **Mutante M306V (Val306):** $\Delta G = -3.820 \text{ kcal/mol}$ (Pérdida de afinidad por impedimento estérico)
